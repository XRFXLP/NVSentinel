#
# Each line has a top-level test name and the E2E_JOB_ID of a job in .github/workflows/e2e-test.yml.
# The other jobs skip the test. A test that is not in this file runs in every job.
#
# Add a test here only if the datastore does not change what it checks: health monitor detection,
# node labels, preflight and janitor requests. Keep tests for quarantine, drain, remediation, the
# health events analyzer, the platform connector, resume tokens and the CSP health monitor, which
# has its own datastore, out of this file.
#
# Every health monitor that can publish to the deployment platform connector keeps at least one
# test in the deployment platform connector job of its architecture.
#
# To balance the jobs, use the test durations in results/e2e-tests.json of each job.
